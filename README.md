# Animal Not Crossing

A free, ad-free, offline puzzle game for one player, installed on an iPhone as a home-screen web app.
Place one animal in every row, column and colored region, with no two animals touching, even diagonally.

Static files only: no backend, accounts, analytics, ads, dependencies or build step.

## Run locally

```
npm test        # unit tests (Node's built-in runner)
npm run bench   # generates PERF.md with measured generator numbers
npm run serve   # http://localhost:8080/ (service workers work on localhost)
```

Requires Node 20 or newer. Nothing to install beyond Node.
